MESTERKALK – ÖNÁLLÓ PWA

Ez a verzió nem használ Python-t, Flaskot vagy app.py-t.

Windows:
- Dupla kattintás az index.html fájlra, vagy a start_local.bat fájlra.

GitHub Pages:
1. A ZIP tartalmát töltsd fel a repository gyökerébe.
2. Az index.html közvetlenül a repository gyökerében legyen.
3. A css és js mappák is közvetlenül mellette legyenek.
4. Settings > Pages > Deploy from a branch > main > /(root).

iPhone:
- Nyisd meg a GitHub Pages HTTPS címét Safariban.
- Megosztás > Hozzáadás a Főképernyőhöz.

Fontos: iOS-en a PWA telepítését Safari támogatja. Az első betöltéshez HTTPS-es webcím szükséges.
